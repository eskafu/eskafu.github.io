# Guia LoRA — 24 Poses

Pacote estático pronto para GitHub Pages. Não precisa de Node.js, instalação ou compilação.

## Publicar

1. Colocar todo o conteúdo desta pasta na raiz do repositório GitHub.
2. No GitHub, abrir **Settings → Pages**.
3. Em **Build and deployment**, escolher **Deploy from a branch**.
4. Selecionar a branch **main** e a pasta **/(root)**.
5. Guardar e aguardar a publicação.

Também funciona localmente: abrir o ficheiro `index.html` num navegador moderno. O progresso é guardado apenas no navegador utilizado.
